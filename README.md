# Claire & Daniel — site de mariage

V1 statique, conçue pour être hébergée gratuitement sur GitHub Pages ou Cloudflare Pages.

## 1. Modifier les deux éléments obligatoires

Ouvrir `script.js` et remplacer :

- `potUrl` par l'URL de votre cagnotte.
- `rsvpEmail` par l'adresse qui recevra les réponses RSVP.

## 2. Tester localement

Double-cliquer sur `index.html` fonctionne pour une première vérification.

Pour une vraie prévisualisation locale, on peut aussi utiliser un petit serveur local.

## 3. Mise en ligne recommandée

Option simple : GitHub Pages.

1. Créer un compte GitHub.
2. Créer un dépôt public, par exemple `claire-daniel-mariage`.
3. Importer tout le contenu de ce dossier.
4. Activer GitHub Pages dans Settings > Pages.
5. Le site sera d'abord disponible sur une adresse `github.io`.
6. Ensuite, connecter votre nom de domaine personnalisé.

Documentation officielle :
https://docs.github.com/fr/pages/quickstart

## 4. Domaine

Nous choisirons d'abord le nom de domaine définitif, puis nous ferons la configuration DNS.
