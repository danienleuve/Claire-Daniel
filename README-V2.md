# Claire & Daniel — V2

Cette archive contient les **3 fichiers à remplacer** dans votre dépôt GitHub :

- `index.html`
- `styles.css`
- `script.js`

Elle ne contient volontairement pas le dossier `assets/` : vous avez déjà remplacé certaines images directement dans GitHub et il ne faut pas les écraser.

## Nouvelle image Kit cat

La V2 appelle cette image :

`assets/photokitcat.jpg`

Ajoutez donc votre photo sous exactement ce nom dans le dossier `assets/` de GitHub.

## Pour installer la V2

Dans votre dépôt GitHub :

1. `Code` → `Add file` → `Upload files`
2. Déposez `index.html`, `styles.css` et `script.js`
3. Conservez vos fichiers actuels dans `assets/`
4. Ajoutez `photokitcat.jpg` dans `assets/`
5. `Commit changes`

GitHub Pages se mettra ensuite à jour automatiquement.
